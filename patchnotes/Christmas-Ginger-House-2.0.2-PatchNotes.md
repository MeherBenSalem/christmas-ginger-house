# Christmas Ginger House 2.0.2

Now available for Minecraft 26.3.

## New
- Minecraft 26.3 is now supported on Fabric (with Fabric API) and NeoForge. Everything from 2.0 "The Christmas Update" is there: gingerbread houses and Christmas trees in the snow, presents, the advent calendar, reindeer, gingerbread men, Krampus, the decorations, food and gear.

## Versions
- 2.0.2 is out for Minecraft 1.20.1 (Fabric, Forge), 1.21.1 (Fabric, NeoForge), 26.2 (Fabric, NeoForge) and 26.3 (Fabric, NeoForge). Nothing changes in play on the older versions.
- Each file now only loads on the Minecraft version it was made for. Pick the file that matches your game exactly.
- Minecraft 26.1.2 gets no new builds. The earlier files for it stay available.
